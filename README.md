# سیستم مدیریت عملکرد IPNA
## IPNA Performance Management System

سامانه مدیریت و ارزیابی عملکرد تیم خبرنگاران، عکاسان و تولیدکنندگان محتوای خبرگزاری ورزشی **IPNA**

---

## ویژگی‌ها

- **داشبورد مدیریتی** - نمایش KPIها، نمودارها و رتبه‌بندی تیم
- **ثبت فعالیت روزانه** - فرم سریع و ساده برای ثبت فعالیت (بهینه برای موبایل)
- **گزارش‌گیری** - روزانه، هفتگی و ماهانه
- **رتبه‌بندی** - بر اساس امتیاز با tie-breaker
- **مدیریت کاربران** - ایجاد، ویرایش، حذف کاربران
- **اهداف ماهانه** - تعیین و پیگیری اهداف
- **وارد کردن اطلاعات** - Import از فایل CSV/Excel
- **خروجی گزارش** - Export به CSV/Excel
- **PWA** - Progressive Web App برای استفاده در موبایل
- **رابط کاربری فارسی** - RTL با فونت وزیرمتن

## الزامات سرور

- PHP 8.0 یا بالاتر
- MySQL 5.7+ یا MariaDB 10.3+
- PDO extension
- mbstring extension
- قابلیت نوشتن فایل (برای config و storage)

## نصب روی هاست cPanel/DirectAdmin

### مرحله ۱: آپلود فایل‌ها

1. فایل پروژه را دانلود و Extract کنید
2. محتویات پوشه `ipna-pms` را از طریق File Manager یا FTP به ریشه هاست آپلود کنید
3. مطمئن شوید فایل `public/index.php` در مسیر اصلی قابل دسترسی باشد

### مرحله ۲: تنظیم دایرکتوری

اگر هاست شما Document Root جداگانه دارد:

1. Document Root را روی پوشه `public/` تنظیم کنید
2. یا فایل `.htaccess` ریشه را ویرایش کنید (از قبل موجود است و تمام درخواست‌ها را به `public/` هدایت می‌کند)

### مرحله ۳: دسترسی دایرکتوری‌ها

مطمئن شوید دایرکتوری‌های زیر قابل نوشتن باشند:

```
/config/
/storage/
/storage/logs/
```

### مرحله ۴: نصب

1. مرورگر را باز کنید و آدرس سایت را وارد کنید
2. صفحه نصب به صورت خودکار باز می‌شود
3. مراحل نصب را دنبال کنید:
   - **مرحله ۱**: بررسی الزامات سیستم
   - **مرحله ۲**: اطلاعات پایگاه داده (Host, Database Name, Username, Password)
   - **مرحله ۳**: ایجاد حساب مدیر (نام، ایمیل، نام کاربری، رمز عبور)
   - **مرحله ۴**: تنظیمات سایت
   - **مرحله ۵**: نصب خودکار

4. پس از نصب موفق، با حساب مدیر وارد شوید

### حساب پیش‌فرض

پس از نصب:
- **نام کاربری**: همان چیزی که در مراحل نصب وارد کردید
- **رمز عبور**: همان چیزی که در مراحل نصب وارد کردید

## انواع فعالیت و امتیازدهی

| نوع فعالیت | کد | امتیاز | دسته‌بندی |
|---|---|---|---|
| خبر عادی | news | 1 | خبر |
| خبر اختصاصی | exclusive_news | 3 | خبر |
| مصاحبه | interview | 4 | خبر |
| گزارش ویژه | special_report | 5 | خبر |
| عکس خبری | news_photo | 1 | عکس |
| گالری عکس | photo_gallery | 3 | عکس |
| ویدئوی اختصاصی | exclusive_video | 5 | ویدئو |

**نکته**: امتیازدهی قابل تنظیم است و مدیر می‌تواند نوع فعالیت جدید اضافه کند.

## امنیت

- رمز عبور با `password_hash()` و Bcrypt هش می‌شود
- محافظت CSRF در تمام فرم‌ها
- Prepared Statements برای جلوگیری از SQL Injection
- XSS Protection با `htmlspecialchars()`
- Rate Limiting برای ورود (حداکثر 5 تلاش در 15 دقیقه)
- Session Regeneration پس از ورود
- ثبت تمام عملیات در Audit Log
- محافظت از دایرکتوری‌های حساس با `.htaccess`

## عیب‌یابی

### خطای اتصال پایگاه داده
- اطلاعات فایل `config/database.php` را بررسی کنید
- مطمئن شوید پایگاه داده وجود دارد و کاربر دسترسی کافی دارد

### خطای 500
- فایل `storage/logs/` را بررسی کنید
- `display_errors` را فعال کنید

### صفحه سفید
- `error_reporting` را فعال کنید
- فایل `phpinfo()` ایجاد کنید تا افزونه‌ها را بررسی کنید

## پشتیبانی

برای گزارش مشکل یا پیشنهاد، با تیم فنی IPNA تماس بگیرید.
