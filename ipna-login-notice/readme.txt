نمایش پیام پاپ‌آپ خوش‌آمد بعد از ورود و پیام خداحافظی بعد از خروج کاربر.

== Description ==

* پس از ورود کاربر، یک پاپ‌آپ با پیام خوش‌آمد (با نام کاربر) نمایش داده می‌شود.
* پس از خروج، کاربر به سایت بازگردانده می‌شود و پیام خداحافظی می‌بیند.
* متن‌ها از **تنظیمات → پیام ورود/خروج** قابل ویرایش است؛ با جای‌نگهی `{name}` برای نام کاربر.
* پیام فقط یک‌بار در هر ورود/خروج نشان داده می‌شود (با transient) و بعد از ۱۲ ثانیه یا با کلیک بسته می‌شود.

== Installation ==

1. پوشه‌ی `ipna-login-notice` را نصب یا zip را از پیشخوان آپلود کنید.
2. فعال کنید.
3. از **تنظیمات → پیام ورود/خروج** متن‌ها را در صورت نیاز ویرایش کنید.
