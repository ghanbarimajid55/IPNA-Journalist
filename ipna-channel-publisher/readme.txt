ارسال خودکار تیتر، عکس و لینک هر خبر منتشرشده به کانال تلگرام و کانال بله.

== Description ==

با انتشار هر خبر در وردپرس (post_type قابل‌تنظیم)، این افزونه به‌صورت خودکار:

* تیتر (عنوان) خبر را می‌فرستد
* تصویر شاخص (featured image) را به‌همراه کپشن ارسال می‌کند (قابل خاموش‌کردن)
* لینک مستقیم خبر را در پیام قرار می‌دهد

ارسال به‌صورت غیرمسدودکننده (زمان‌بندی‌شده با wp-cron) انجام می‌شود تا انتشار خبر کند نشود.

== Installation ==

1. پوشه‌ی `ipna-channel-publisher` را در `wp-content/plugins/` کپی یا zip را از پیشخوان نصب کنید.
2. افزونه را فعال کنید.
3. به **تنظیمات → IPNA انتشار کانال** بروید.
4. توکن ربات و شناسه‌ی کانال تلگرام و/یا بله را پر کنید و فعال کنید.
5. با دکمه‌ی «ارسال پیام آزمایشی» صحت را تست کنید.
