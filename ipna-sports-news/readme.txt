موتور جمع‌آوری و بازنویسی اخبار ورزشی از RSS + صفحه خبر با هوش مصنوعی و ذخیره به‌صورت پیش‌نویس وردپرس.

== Description ==

این پلاگین از فید RSS سایت‌های معرفی‌شده، اخبار ورزشی را مطابق کلمات کلیدی و دسته‌های ورزشی جمع‌آوری می‌کند و برای هر خبر:

* تیتر، روتیتر (زیرتیتر)، متن کامل، تصویر شاخص، کلمات کلیدی/تگ و تاریخ انتشار را استخراج می‌کند.
* در صورت نیاز صفحه‌ی خبر را باز می‌کند و متن کامل + عکس og + کلمات کلیدی را می‌گیرد (استخراج عام).
* تیتر و متن را با هوش مصنوعی (OpenAI یا Gemini) بازنویسی می‌کند.
* نتیجه را به‌صورت **پیش‌نویس وردپرس** ذخیره می‌کند (قابل ویرایش پیش از انتشار).
* جمع‌آوری با زمان‌بندی (wp-cron) یا با دکمه‌ی «اجرای همین حالا» انجام می‌شود.
* تکرارها (URLهای قبلاً دیده‌شده) را نادیده می‌گیرد.

== Installation ==

1. پوشه‌ی `ipna-sports-news` را نصب یا zip را از پیشخوان آپلود کنید.
2. فعال کنید.
3. منوی **اخبار ورزشی**:
   - در «منابع خبری»، هر خط یک منبع: `نام | آدرس RSS | انتخابگر (اختیاری)`.
   - کلمات کلیدی و دسته‌های ورزشی را تنظیم کنید.
   - سرویس هوش مصنوعی (OpenAI/Gemini)، کلید API و مدل را وارد کنید.
   - نوع پست، وضعیت (پیش‌نویس) و حداکثر تعداد در هر اجرا را بگذارید.
4. «ذخیره» و سپس «اجرای همین حالا» را بزنید.
