اتصال مستقیم به دیتابیس سامانه مدیریت عملکرد IPNA و تحلیل تعداد اخبار و عملکرد هر کاربر.

== Description ==

این پلاگین دیتابیس سامانه مدیریت عملکرد خبرنگاران (PMS) را به صورت مستقیم می‌خواند و موارد زیر را فراهم می‌کند:

* داشبورد مدیریتی با نمودارهای تولید روزانه، سهم دسته‌ها و امتیاز به تفکیک هر کاربر.
* فهرست کاربران به همراه تعداد اخبار، عکس، ویدئو و امتیاز هر کاربر.
* مقایسه عملکرد هر کاربر با اهداف ماٰهانه (targets) و نمایش درصد تحقق.
* هشدار خودکار روزانه (ایمیل) زمانی که کاربران به آستانه‌ی عملکرد می‌رسند.

== Installation ==

1. پوشه‌ی `ipna-report` را در `wp-content/plugins/` کپی کنید.
2. از منوی پیشخوان → افزونه‌ها، افزونه را فعال کنید.
3. از منوی **IPNA Report → تنظیمات**، اطلاعات اتصال دیتابیس PMS را وارد کنید.
4. اگر به `person` نیاز دارید، در همان بخش هشدارها فعال کنید.
